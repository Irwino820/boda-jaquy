# Fotografía de la invitación

Fotos reales de Pepe y Jaquelin. Los originales de WhatsApp se copiaron a
nombres limpios (sin espacios) para URLs estables.

El manifiesto vive en `src/config/photos.ts`. Para añadir más fotos: copia el
archivo a esta carpeta con un nombre sin espacios y registra `src` / `width` /
`height` ahí.
